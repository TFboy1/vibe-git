# 队长创建房间

## 步骤 1：选择产品工作区

> **操作人**：队长。**前置条件**：已完成[新版安装](./install.md)。**入口**：本机终端，选择你要开发的产品目录。

本例使用 `D:\Projects\todo-app`，它与 Vibe-Git 工具源码目录分开。已有代码先确认是正确仓库，队友通常各自克隆同一个产品仓库。

CLI 可以创建新项目目录并初始化 Git；已有源码不会被自动提交。显式填写绝对路径，避免首次启动时使用默认项目。

**成功结果**：选定正确产品工作区。**失败处理**：路径选错时停止，不在工具安装目录启动房间。**下一步**：启动 Host。

## 步骤 2：启动 Host 并打开页面

> **操作人**：队长。**前置条件**：项目路径确定。**入口**：本机 PowerShell，任意目录；替换示例路径。

```powershell
vibe-git host start "D:\Projects\todo-app"
vibe-git host status
vibe-git open
```

启动会建立本机 Host、队长节点和后台连接，并输出成员加入命令。`open` 打开本机会话，它不是邀请命令。加入命令只私发给预期队友。

**成功结果**：Host 运行，网页进入工作台。**失败处理**：端口或启动超时错误先检查 `vibe-git logs` 与具体回执，不重复创建不同项目。**下一步**：确认身份。

## 步骤 3：确认身份并设置名字

> **操作人**：队长。**前置条件**：页面已打开。**入口**：Settings → 个人资料、团队成员。

1. 执行 `vibe-git status`，确认 `node.role` 是 `captain`。
2. 在 Settings → 个人资料填写名字并保存，或执行 `vibe-git profile set "我的名字"`。
3. 确认 Settings 显示“队长权限”，团队成员中本人是队长。

**成功结果**：本人节点与权限一致。**失败处理**：缺少管理按钮时重新从本机 `vibe-git open` 进入，检查是否连接了成员节点。**下一步**：配置算力和邀请。

## 步骤 4：配置算力并邀请队友

> **操作人**：队长。**前置条件**：身份确认。**入口**：Settings → 算力与 API；Settings → 团队成员。

1. 按[配置算力](./compute.md)连接 Codex 节点池或测试 API。
2. 到团队成员点击 **“邀请成员”**。
3. 复制完整邀请命令，私发给队友；复制失败可在页面手动选择。
4. 队友按[成员教程](./member.md)连接自己的项目，再运行 `vibe-git open`。
5. 在团队列表确认预期队友已出现且在线。同名成员通过节点 ID 区分。

也可以在终端读取邀请：

```powershell
vibe-git invite show
```

**成功结果**：算力可用，预期成员已注册。**失败处理**：邀请失效先检查 Host 与 Tunnel 地址，再读取当前邀请；暂时离线时检查成员端状态。**下一步**：队长和成员一起[提交计划](./plans.md)。

## 房间与页面的区别

官网提供教程，团队工作台由 CLI 打开。访问远程地址不能替代连接自己的工作区；出现“请在自己的电脑运行 vibe-git open”时，从本机重新打开即可。
