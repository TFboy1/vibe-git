# 成员加入房间

## 步骤 1：准备自己的工作区和邀请

> **操作人**：成员。**前置条件**：通过[能力检查](./install.md#capability-check)。**入口**：自己的电脑与队长私发的邀请。

准备本机产品 Git 工作区，如 `D:\Projects\todo-app`。开发已有产品时先克隆正确仓库，邀请不会自动把整个源码传给你。获取队长的完整加入命令，保留 `/join/` 后的内容，不能使用官网或示例 URL。

**成功结果**：有自己的项目路径和有效邀请。**失败处理**：缺少或过期时请队长重新生成。**下一步**：连接。

## 步骤 2：连接自己的项目

> **操作人**：成员。**前置条件**：步骤 1 完成。**入口**：本机 PowerShell；占位符替换为真实 URL。

```powershell
vibe-git connect "<队长私发的完整加入 URL>" "D:\Projects\todo-app"
vibe-git status
```

也可执行队长发来的完整命令，并使用自己的项目路径。带空格的路径保留引号。`status` 返回本人 `node`、后台连接状态、房间和本人任务；确认 `node.role` 是 `member`。

**成功结果**：连接成功，状态显示正确房间与本人节点。**失败处理**：核对 URL、路径、Host 和网络，不删除配置后反复注册。**下一步**：设置名字并打开页面。

## 步骤 3：设置名字并打开页面

> **操作人**：成员。**前置条件**：CLI 连接成功。**入口**：同一台电脑的终端。

```powershell
vibe-git profile set "我的显示名字"
vibe-git open
```

也可在 Settings → 个人资料修改名字。团队成员中标有“你”的节点应与终端一致。成员页面不提供队长整合和派发按钮。

**成功结果**：显示正确团队、名字和成员权限，可以编辑自己的计划。**失败处理**：远程只读提示时重新运行本机 `vibe-git open`；连接恢复中时检查 `status` 和 `logs`。**下一步**：让 Agent 同步。

## 步骤 4：让当前 Agent 同步

> **操作人**：成员及当前开发 Agent。**前置条件**：Skill 安装，房间连接完成。**入口**：产品工作区的 Agent 会话。

发送：

> 我是成员，已加入 Vibe-Git。请使用 vibe-git Skill，先读取 task inbox 和当前状态，再阅读项目，按目标、范围、方案、验收和风险起草我的计划。先展示给我确认，确认后保存为 UTF-8 Markdown 并提交。

每次调用 Skill 先同步任务修订和暂停消息。连接房间不会自动运行另一段开发会话。

**成功结果**：Agent 确认当前状态并起草计划；提交成功后团队才可见。**失败处理**：找不到 Skill 时回到[安装 Skill](./install.md#install-skill)。**下一步**：[提交个人计划](./plans.md)。
