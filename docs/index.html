INSTALL / START HERE

只选一条路。

推荐 Agent 自动安装。你不需要先记 npm 命令，也不需要先进入 Vibe-Git 源码目录。

RECOMMENDEDAGENT MODE

只安装 Skill，让 Agent 代你装 CLI。

Skill 会检查环境；发现 CLI 缺失时，按你的指令执行 npm 安装，然后继续问你是队长还是队员。

先安装一次 Skill
npx skills add TFboy1/vibe-git-skill --skill vibe-git
“请自动安装并配置 Vibe-Git；如果 CLI 没安装就执行 npm install -g @vibe-git/vibe-git，安装成功后先问我是队长还是队员，再带我开始。”
查看 Skill ↗
MANUALCLI MODE

自己安装 npm CLI。

适合不允许 Agent 执行终端命令，或希望手动控制安装过程的人。

PowerShell / Terminal
npm install -g @vibe-git/vibe-git
vibe-git --help

需要 Node.js 24+、Git 和 Codex CLI。手动装好 CLI 后，仍然可以安装 Skill，让 Agent 帮你使用。
