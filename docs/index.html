01 / INSTALL

两部分，分别安装。

Skill 教会 Codex 如何协作。CLI 提供房间和命令。先装 Skill，再手动安装 CLI。

01CODEX SKILL

给你的 Agent 安装 Skill

在需要使用 Vibe-Git 的项目里执行。安装后，Codex 可以协助连接房间、提交提案和推进任务。

TERMINAL
npx skills add TFboy1/vibe-git-skill --skill vibe-git

↳ 在 Codex 中可使用 $vibe-git 调用。

查看 Skill 文档 ↗
02CLI / MANUAL

手动安装 npm CLI

需要 Node.js 24+、Git 和 Codex CLI。CLI 需要在终端单独安装，安装 Skill 不会自动安装它。

TERMINAL
npm install -g @vibe-git/vibe-git

↳ 安装后运行 vibe-git --help 检查命令。

查看 npm 包 ↗

02 / FIRST SESSION

开一个房间，开始对齐。

队长托管 Host，每位成员从自己的 Git 工作区加入。加入链接由队长发给预期成员。

01

队长启动

在队长自己的项目工作区执行。

CAPTAIN
vibe-git host start
vibe-git open
02

成员加入

在成员自己的项目工作区执行，替换为队长给你的链接。

MEMBER
vibe-git connect <join-url>
vibe-git plan submit proposal.md

03 / WORKFLOW

从计划到交付。

完整 CLI 手册 ↗
01PLAN

成员提交各自的 Markdown 提案。

plan submit
02ALIGN

队长发起对齐并裁决冲突。

align start
03BUILD

发布任务，负责人开始执行。

tasks publish
04CHANGE

记录变更，审核受影响的任务。
