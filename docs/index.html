WHY / 01

让“大家都在写代码”变成“大家都在做同一个项目”。

多个 Agent 可以同时产出正确代码，却仍然实现不同需求。Vibe-Git 在 Git 工作区之上，补上团队决定、任务边界、交接证据和需求变更的上下文。

提案每位成员提交一份可追踪 Markdown 计划。
对齐队长冻结决策，拆出有负责人和依赖的任务。
交接同步 Git、Codex 阶段与真实集成状态。
变更需求变化有影响证据，不再静默漂移。
GET STARTED / 02

三步进入协作房间。

需要 Node.js 24+、Git 和 Codex CLI。队长先开房间，成员使用邀请链接连接自己的 Git 工作区。

01

安装 CLI

npm install -g vibe-git
02

队长启动房间

vibe-git host start
vibe-git open
03

成员连接并提交计划

vibe-git connect <join-url>
vibe-git plan submit proposal.md
CLI MAP / 03

常用命令。

完整使用手册 ↗
角色阶段命令
队长对齐vibe-git align start
队长发布vibe-git tasks publish <alignment-id>
成员计划vibe-git plan submit proposal.md
成员执行vibe-git task start <task-id>
成员完成vibe-git task sync && vibe-git task done <task-id>
队长变更vibe-git review start --force
